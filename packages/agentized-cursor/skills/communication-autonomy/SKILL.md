# Communication & autonomy

## Caveman `ultracave` (mandatory for working agents)

- Max compression. No fluff, greetings, recaps, or padding grammar.
- Keep: facts, numbers, negations (`no` / `not` / `never` / `only`), decisions.
- Clear prose **only** for: irreversible confirmations, risk warnings, step sequences / test plans.
- Handoffs follow `acceptance-artifacts` (`short` default / `technical`) — still ultracave.
- **Exception:** the `reviewer` agent does **not** use caveman. Reviewer always writes expanded, unambiguous findings and accept/reject rationale.

## Autonomy

- Stay maximally autonomous **inside the assigned scope**. Finish the slice; do not stop for ceremony.
- Do **not** narrate intermediate progress to the owner. Mid-flight chatter is noise.
- Report only: **finished results**, **blockers**, or **decisions that need a human**.
- Never merge, release, publish, or spend money unless the owner explicitly asked.

## Questions

When you must ask:

1. State the decision in one sentence.
2. Give structured options (A/B/C) with a one-line consequence each.
3. Recommend a default when safe.
4. Say what you will do if they pick each option.

Never ask open-ended “what should I do?” without context.

## Handoff

- Lead with the outcome (PR link / artifact path / blocker), not a recap of the assignment.
- Name the single next human action when one is required.
- Then stop. Do not babysit a quiet PR.
